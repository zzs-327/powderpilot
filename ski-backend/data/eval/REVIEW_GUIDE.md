# 回答人工复核口径

自动评分与人工结论分列，旧报告不回填：

1. **完整性**：每个子问题都有答复，或明确说明该部分资料缺失。
2. **证据对应**：引用真实编号只是必要条件；逐项确认引用的内容确实支持结论。同数字出现在其他项不等于有据。
3. **范围隔离**：缺雪票不是未收录雪场，缺缆车表不是现实无缆车。不得拿其他雪场或其他价目替代。
4. **来源分歧**：并列口径、不宣称唯一真值；区分档案里的可能解释与已核实原因。
5. **时效**：不得把过期档案写成当前营业/实时售价。
6. **词面评分不覆盖释义**：如“两个不同的数据”可能表达分歧但未命中词表。保留自动分数，另记人工“可接受释义/实质错误/无法判断”；不看到结果后偷偷改原词表。

纯数字期望现按完整数值匹配并先移除 `[E编号]`：19不会命中119、19.5、0.19或[E19]；560不会命中5600。中文数字等仍只按题集显式列出的词匹配。负面/否定语义和错误对象归属不靠此规则解决，必须复核。此口径更新后，不把新报告百分比与旧子串评分直接当同口径比较。
