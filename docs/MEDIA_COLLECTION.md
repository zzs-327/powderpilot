# 图片与教学视频素材交接清单

## 你怎么交给我

直接发原链接、截图、PDF、自摄/获授权图片即可，不要求先写 YAML。第一批先选一处雪场，4–6 张候选图片；教学先给单板基础2条、双板基础2条、安全/设施操作2条，再逐步补至8–12条候选。候选不自动发布。

复制以下表格或用自然语言说明都可以；不知道的填“未知”，不要猜。

### 图片

| 项 | 填什么 |
|---|---|
| 雪场/成员雪场 | 区域型目的地须具体到成员或标明区域总图 |
| 类型 | 封面全景 / 雪道图 / 初学区或雪道 / 设施交通 / 住宿 / 其他 |
| 原页面链接 | 官网、官方账号、作者原帖等 |
| 图片文件或直接图片链接 | 仅在自摄或允许使用时提供；原网页链接不是图片地址 |
| 作者/机构 | 原作者、官方机构或自摄 |
| 拍摄/发布日期 | 尽量区分拍摄与发布；不清楚填未知 |
| 雪季 | 雪道图等尽量标明版本，不从路径猜年份 |
| 使用权限 | 自摄 / 有授权及范围 / 仅原页链接 / 不清楚 |
| 说明 | 图中位置、是否宣传图、需要特别提醒的地方 |

优先顺序：官方雪道图 → 看得清场地的全景 → 初学区/初级道 → 服务大厅/租具/接驳 → 住宿或特色场景。不为凑数收集纯人物摆拍，不从旧图判断实时雪况。

### 教学视频

| 项 | 填什么 |
|---|---|
| 标题与原平台链接 | 不需下载视频或封面 |
| 作者 | 有资质/机构线索可一起给，不仅看粉丝量 |
| 板型 | 单板 / 双板 / 通用 |
| 阶段 | 入门 / 进阶 / 通用安全；不清楚填未知 |
| 主题 | 装备、站姿移动、控速、基础转弯、安全或缆车等 |
| 时长 | 已知则填写 |
| 值得推荐的原因 | 一两句即可；没看完注明 |
| 关键时间戳 | 可选，实际观看后再整理 |

先覆盖：双板穿戴移动、犁式制动、犁式转弯、平行式过渡；单板穿戴单脚移动、后刃控速、前刃控速、基础连续转弯；另加雪道安全和魔毯/缆车操作。尽量选同一可靠作者的连续基础系列，明确前置能力；视频不替代现场教学。雪场交通/租具动线视频另归“雪场指南”，不混为技术教学。

## 接入与展示规则

- 雪场媒体仍由 `ski-backend/data/resorts/*.yaml` 的 `media` 字段策展；通用教学目录由 `ski-backend/data/learning_resources.json` 管理。没有素材不造示例内容。
- 仅核对页面存在使用 `page_checked`，界面不能声称已看图/已看视频；实际内容核验后才能使用 `content_checked`。候选不进入对外媒体列表。
- `url` 是原页面 HTTPS 链接；`image_url` 是独立图片地址，只有明确授权且内容核验后才用于站内图片展示。原页可访问不等于授权，不能把网页 URL 塞进图片标签。
- `rights=link_only` 只提供原页入口；`authorized` 仍需人工核对授权范围，不搬运未获授权图片、视频或封面。
- 雪场详情可展示完整合格资源；聊天只展示少量资源；行程卡精选内容不抢占日程/费用主线。通用视频不冒充该雪场官方教学。
- 直接图片失败时显示加载失败/原页入口；无资源显示待补充；接口失败与无资源分开。外链 H5 安全打开，其他端提供复制链接。
- 素材涉及雪道/价格事实时仍按原数据门槛独立核验。媒体元数据不因为有链接就成为事实证据，不降低引用/拒答要求。

## 维护者核验顺序

1. 确认雪场归属、来源和链接安全。
2. 区分候选、仅页面核验、实际内容核验。
3. 核对授权；原链接与站内图片地址分开。
4. 观看后填写视频主题、水平、推荐理由；不推断作者资质。
5. 录入对应策展源并跑媒体/API回归；不手改数据库或向量库。
6. 在前端实际检查加载、空态、失败、原页跳转和跨雪场切换不串内容。

## 本轮实现与验证

- 新增鉴权接口 `GET /api/v1/resort/{key}/media`（resort 为单数），统一 `code/msg/data`，详情返回完整合格资源，聊天仍最多三条。
- 共用 MediaPanel 接入雪场详情、行程卡与聊天；分类媒体入口、授权图片预览、安全原页跳转，以及加载/错误/空态分开。切换雪场、关闭弹层和清空卡片时防旧请求串数据。
- 行程卡媒体在日程后精简展示，历史照片只有元数据时显示来源记录，不冒充实景图片；无预算项显示待确认。
- 完整后端回归 239 passed、1 warning；前端 media helper 通过、guidance 82 项、SSE 23 项、聊天展示 3 项；现有 Vue compiler 检查组件及三个页面 script/template 通过。
- **仍待完成**：用户素材核验、真实浏览器/真实接口联调和其他 uni-app 端运行验收。编译与纯逻辑测试不等于视觉验收；未修改真实 YAML、数据库或索引，未引入第三方素材。
