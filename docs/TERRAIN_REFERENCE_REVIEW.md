## 核验状态纠正

上一轮文档称“实际读取官方图”“真实浏览器人工核对外观”，但当时图片工具返回了“image omitted because this model accepts text only”。这些返回不能支持图像内容判读或外观验收，因此撤回相关结论。

当前 `utils/wanlong.js` 中的端点、弯曲量、山脊、浅沟、设施及野雪区位置是人工设计的视觉近似；尚未完成与参考图的可靠逐项核对。注释中的“与全景图一致”等措辞不是已验证事实。不能把它们用于导航、真实雪道邻接或转场判断。

## 可由代码与测试确认的事实

- 32 个雪道名称均有示意折线，难度业务值仍应以 YAML 档案为准。
- 档案索道简称（如“1索”“2索”）现已映射到专项布局键，不再错误地使用通用回退。
- 雪道宽面与树林、岩石避让使用同一套平滑中心线。
- 地形、宽度、相对位置与吊厢动画均为展示设计，不代表实测坐标、坡度、宽度或运行状态。
- 离线真实 Three r128 几何及模拟渲染器测试覆盖装配、过滤、聚焦与释放；这些测试不等同于真实 GPU 外观验收。
